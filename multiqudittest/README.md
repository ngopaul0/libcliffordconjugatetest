# multiqudittest

A test program to import Clifford gates generated by the `cliffordhierarchy` Python scripts originally from
https://github.com/ndesilva/cliffordhierarchy/ and to use them all to conjugate a matrix to test the Clifford-conjugate
test algorithm.

Program is currently hardcoded for $n = 2, d = 3$. It will import all Clifford gates on 2 qutrits (4,199,040 of them)
and run the conjugacy test on some hardcoded test matrix $M$.

## Requirements

```
# On macOS with Homebrew
brew install boost sqlite

# On Debian-based Linux systems
sudo apt-get install libboost-all-dev libsqlite3-dev

# On Windows, install Boost, SQLite3 via vcpkg
```

OpenMP is needed for multithreading. Windows and Linux usually has support for this (might need to install a package).

Since all Clifford gates for $n = 2, d = 3$ are precreated and loaded, ~5.4 GB is needed for the Clifford gate file.

~11 GB RAM / swap is needed for the program will load all gates in memory. The program will also use multiple threads,
so a CPU with more cores / threads will run faster.

A better way could be to just write code to generate random a Clifford in C++, but listing out all Clifford gates
allows us to check it for all possible Cliffords and with parallel algorithms.

## Running instructions

The Clifford gates need to be pre-generated (code to generate arbitrary Cliffords not implemented in C++ yet).

Run the Python script to generate: `python3 cliff.py`. It will take a while to generate. The resulting Clifford 
gates file (``n2-c2-gates-d3-asGATES.npy``) will be around 5.4 GB (all the more reason to generate directly in C++!). 
Move `n2-c2-gates-d3-asGATES.npy` to the project root directory.

Then build the multiqudittest executable. In the project root directory (skip the first step if already initialized):

```
$ cmake -DCMAKE_BUILD_TYPE=Release -B cmake-build-release
$ cmake --build cmake-build-release --target multiqudittest -j 10
```

where the `-j` argument is the number of threads.

Run the executable by doing `cmake-build-release/multiqudittest/multiqudittest` in the project root directory so that
it detects the gates file.

When done correctly, the program lines will look like:

```
Verified 970971 gates out of 4199040 (i = 970978 took 33163956ns / 33ms, avg micro seconds 54325)
```
